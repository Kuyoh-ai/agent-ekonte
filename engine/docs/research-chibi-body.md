# ちびキャラ（2頭身）ボディの構築ルール — コード化のための整理

（調査メモ。主要講座サイトは直接フェッチできず、検索スニペットの本文抜粋を統合。「出典」付きはスニペット由来、「※推奨値」は複数出典の記述から幾何学に落とした既定値。）

## 0. 共通原則
- **ぬいぐるみ / 赤ちゃん体型**。腹・関節にくびれをつけない（女の子は腰にわずかだけ）。
- **関節は描かない**（rubber hose）。手足は stubby cylinder / noodle。曲げは中心線を折るだけで、外側輪郭は連続した弧。
- 手足の先は指や靴を省略して丸い筒に。直線より曲線。
- 箱に見える最大の原因: 直線＋角、関節線、シワの多さ、左右対称すぎ。
- 比率: 2頭身 頭:胴:脚 = 1:0.5:0.5。胴は頭より小さめ。腕は腰まで（手先は股下よりわずか下）。万歳しても拳は頭頂を越えない。

## 1. 胴体と腰
- 語彙: 豆（bean）/ 洋梨 / 角丸三角。上が細く下へ丸く広がり、お尻が常に最も広い。なで肩、首は細く短い（または省略）。
- 手順: 頭直下に頭幅 0.6〜0.75 の卵/豆 → 肩は首元から肩先へ一続きの下向き弧（20〜30°）→ 高さ中間よりやや下で最大幅 → 服は豆にかぶせるだけ。裾は腰最大幅の位置で下に凸の弧。オーバーサイズは下半分に布だまり。
- 箱化回避: 肩を水平＋直角で始めない。胴の左右を垂直線にしない（常に外へ凸、下ほど広い）。

コード化: `torso` = 卵: 上幅 0.6H、最大幅 0.8H を高さ 60% に、下端は半円。左右輪郭は 肩点(±0.3H,0) → 制御点(±0.42H,0.35T) → 最大幅点(±0.4H,0.6T) → 下端。肩は首の付け根(±0.1H,−0.05T) から肩点へ下向き弧。裾リブ = 裾弧を 0.08T 下へ平行オフセットした帯、内部に細い縦線 3〜5 本。

## 2. 腕
- 語彙: 長い楕円 / 角の取れた先細り三角 1 個。ソーセージ。肩から手先へ先細り、小さなミトン手。
- 手順: 手 → 腕 → 肩の順（手の位置を先に決めて肩から管を通す）。腕の長さ ≒ 胴の高さ。肘は中心線の折れのみ、外側は大きな弧、内側 1 本の折れ。腕上げ時のシワは脇の短い線 1 本に省略。
- ガッツポーズ: ちびは腕が短いので**拳は顔の横〜こめかみ高さ**。上腕は肩から外上へ 30〜45°、前腕はそこから 90〜110° 折れて上へ。左右の角度を ±10° ずらして非対称に。フォーショートニングは省略し、常に横に展開したシルエットで読ませる。

コード化: `arm(S, E, W)`: 中心線 S→E→W を丸め、幅 w(t)=lerp(0.18H, 0.14H, t) でストローク、両端半円。肘内側にだけ、曲げ角 > 60° のとき「しずく」細線 1 本。下ろした腕: S=(±0.3H, .05T), W=(±0.36H, 1.0T)。ガッツポーズ: S=(±0.3H,.05T), E=(±0.55H,−.15T), W=(±0.45H,−.55T)（拳は顔の横、頭頂を越えない）。

## 3. 手・萌え袖
- 手 = 円 or 角丸正方形（角丸 ≥ 辺の 35%）。指は描かないか親指の小さな膨らみ 1 つ。拳の直径 = 0.2〜0.25H。
- 萌え袖: 袖の下の手の状態で袖の折れが決まる。袖は手を隠す長さで布の余りたっぷり。**袖口を S 字にする**（水平線で切らない）。袖口幅 = 腕幅 × 1.3〜1.5、袖が手を 50〜100% 覆う。オーバーサイズの服でのみ成立。

コード化: `fist` = 角丸矩形 (0.24H × 0.22H, r 0.09H) を腕先に 10〜20° 回転、親指 = 内側上に半径 0.05H の半円。`moe_sleeve`: 袖管幅 1.4×腕幅、袖口で ×1.3。袖口の縁 = S 字（手前側の角が 0.1w 下がる）。袖口直上にたるみ 1 本（袖口幅 40% の斜め細線）+ 外側輪郭を 0.05w 波打たせる。手は袖口下端から 0〜0.5 拳径だけ出す。

## 4. 布の簡略化・パーカー・タートル・プリーツ
- シワは「引っ張り」と「たまり」。起点から描く。肘内側にシワ、外側は張る。ミニキャラは頭身が小さいほどシワを減らす。
- **2頭身で残すシワは 3〜4 本**: 脇の下 1 本（腕上げで 2 本放射）、肘内側のしずく（曲げ時のみ）、裾・袖口直上のたるみ 1〜2 本。
- パーカー: スウェットで丸み。裾・袖口は重力でたまり下側に垂れる。リブは細線 3〜5 本。フードは「2頭身は布の袋を首に巻く」= 首を囲むドーナツ帯 + 背中側の膨らみ 1 つ、シワ 0。紐は V の底から 2 本、先端に小丸。ポケット = 胴下半分の角丸台形。
- タートルネック: ちびは首がほぼ無いので**襟＝顎のすぐ下の横長楕円帯（ロール）**、上縁が顎に接し、折り返しは帯内の平行弧 1 本。
- プリーツ: 円柱をひだ分割、両端ほどひだ幅を狭く（∝ cos）。2頭身はひだ 5〜7、裾は浅いスカロップ。

コード化: `hoodie_body` = torso を 8〜12% 拡大 + 裾リブ帯 + ポケット台形（上辺 0.5H, 下辺 0.6H, 高さ 0.22T）。`hood` = 首を囲む帯 + 背中側の扁平楕円（幅 0.9H, 高さ 0.3H）。`drawstrings` = V 底から 2 本、長さ 0.25T、先端に半径 0.02H の円。`turtleneck` = 顎下の楕円帯（幅 0.55H, 高さ 0.12H）+ 折り返し弧 1 本。`pleated_skirt` = 台形（上辺 0.7H, 下辺 1.1H, 高さ 0.35T）、上辺は上に凸、裾は 5〜7 スカロップ、谷ごとに細線 1 本。

## 5. 脚と足
- 脚 = 股から下へ太もも太く足首細い 1 本の先細り管。膝は描かない。足 = 前方に長い楕円/角丸の靴 + ソール線 1 本。つま先 = 半分に切ったお椀。
- ニーハイ: 太ももとの境界線は太く、ゴムの凹凸は細く。境界の直上で太ももが少し外に膨らむ「むちっ」。
- ジャンプ: 離地で膝曲げ、空中で伸ばす。肘と膝を外側へ、手足をバラバラに、S 字で髪や服をふわっと。定番: 片膝を前に上げ（太もも 60〜90° 前上、脛は 100〜120° 折れて後ろ下）、もう片脚は後ろへ伸ばし、**両足のつま先は下向き**。
- 数値: 脚長 0.5 頭高。太もも幅 0.22H → 足首 0.16H。靴 長さ 0.3H, 高さ 0.14H, ソール 0.03H。

コード化: `leg(P, K, A)`: 中心線を丸め、幅 lerp(0.22H, 0.16H)。立ち: P=(±0.13H,T), A=(±0.14H,T+0.5H)。ジャンプ前脚: K = P + (0.15H 前, −0.05H), A = K + (0.02H, +0.22H)。後脚: K = P + (−0.1H, +0.18H), A = K + (−0.08H, +0.2H)。`shoe` = 角丸カプセル（長さ 0.3H, 高さ 0.14H）を足首下につま先方向へ 60% 前に出す、ソール = 下縁を 0.03H 上にオフセットした弧、ジャンプ時は 20〜40° 下に回転。`thigh_high` = 太もも上部 30% で上に凸の弧（太線）+ 直上で輪郭を 0.02H 膨らませる。

## 6. 線の太さ
- 外側の輪郭・影側は太く、光側・内側は細く。入り抜き。ちび作例: 輪郭 1.25mm / 内側 0.8〜1.0mm（≈ 1.25〜1.5 : 1）。「ちびキャラの外枠だけをさらに太く」（境界効果）。線幅は相対差で決める。

コード化: `L_outer = 0.020H`（シルエット外周のユニオン輪郭）、`L_part = 0.014H`（パーツ境界: 腕と胴、袖口、ニーハイ上端、裾、フード縁）、`L_inner = 0.008H`（シワ、指線、リブ、髪の内側）。内側線は両端テーパー、輪郭はテーパー無し。手前パーツの境界は L_part、奥側の重なり線は描かない。

## 7. 「箱に見える」チェックリスト
1. 肩が水平＋直角 → なで肩の弧
2. 胴が矩形 → 下広がりの豆
3. 腕・脚が同幅の矩形 2 本 → 先細り 1 本管、関節は折れのみ
4. 手が正方形 / 足が長方形 → 角丸 ≥ 35%、つま先半円
5. 袖口・裾が水平直線 → 下に凸 or S 字
6. シワ 5 本以上 → 3〜4 本
7. 線幅が均一 → 外周太く内側細くテーパー
8. 左右対称すぎ → ポーズは左右 10° ずらす
