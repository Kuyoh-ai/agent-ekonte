# ちびキャラをベクター図形でプログラム生成するための技法リサーチ

（調査メモ。ネットワーク制限のため多くのページは検索抜粋ベースで、「推奨値」は出典の定性的記述を筆者がコード化しやすい数値に落としたもの。「出典」と付記した数値は原文に書かれたもの。）

## 1. ちびキャラ／SD キャラの構造（頭身・顔配置・体）

### 1.1 頭身比率
- **2頭身**: 1つ目の円 = 頭、2つ目の円 = 体全体。体の円をさらに半分に割り、上半分が胴、下半分が脚。頭:胴:脚 = **1 : 0.5 : 0.5**（出典）。
- **3頭身**: 頭:胴:脚 = **1 : 1 : 1**（出典）。
- **2.5頭身**: 中間。「かわいさ重視なら2頭身、ポーズやキャラ個性を出すなら2.5〜3頭身」（出典: パルミー）。
- 頭身が下がるほど**輪郭の丸みを強く、線をシンプルに**。

| 頭身 | 頭高 | 胴高 | 脚高 | 全身高 | 頭幅 |
|---|---|---|---|---|---|
| 2 | 1.0 | 0.5 | 0.5 | 2.0 | 0.95〜1.0 H |
| 2.5 | 1.0 | 0.75 | 0.75 | 2.5 | 0.9〜0.95 H |
| 3 | 1.0 | 1.0 | 1.0 | 3.0 | 0.85〜0.9 H |

- 胴の幅 ≈ 頭幅 × 0.55〜0.65。肩幅 ≈ 頭幅 × 0.6。

### 1.2 顔パーツの配置
- 頭の高さを半分に割り、**上半分はすべておでこ（＝髪）**、**下半分に目・鼻・口**。「目は下半分の上側 1/4（頭高の 50〜75%）、頬・鼻・口は下側 1/4（75〜100%）」（出典: TIPS 4870）。
- 「目の中心が十字線か、それより下」「瞳の大きさは頭高の 1/5、瞳と瞳の間は広め」（出典）。目と目の間隔は目 1.2〜1.5 個分。

推奨値（頭の外接矩形、上端 0 / 下端 1）:
- 目の中心 y = **0.60〜0.65**（2頭身は 0.65、3頭身は 0.58）
- 目の高さ = 0.20〜0.25 H、目の幅 = 0.18〜0.22 W
- 両目中心の x 間隔 = **0.42〜0.48 W**
- 眉 y = 目の上端 − 0.05〜0.08 H
- 鼻: 省略、または点を y = 0.74 H
- 口の中心 y = **0.80〜0.85 H**、幅 0.08〜0.15 W（叫び口は 0.3 W）
- 頬（チーク）: x = ±0.30 W, y = 0.72 H に楕円 0.10 W × 0.05 H

### 1.3 顔の輪郭
- 「球体」を意識し**あごも丸く**。2頭身はほぼ真円〜やや横広の楕円で、下側だけわずかに尖らせた「饅頭型」。
- ベジェ: 上半分は円弧（半径 0.5 W）、下半分は頬から下の 2 本の曲線を y = 1.0 で滑らかに会わせる。頬の最大幅は y ≈ 0.55〜0.6 H（目の高さと一致させると「ぷくっ」とする）。

### 1.4 首・手・足・体
- **首**: 2頭身では省略か、幅 0.15 W・高さ 0.05 H。
- **手**: ミトン型か丸。頭幅の 0.12〜0.15。
- **足**: 靴を含めて丸い楕円 or 半円。幅 0.15〜0.18 W、高さ 0.08 H。
- **胴体**: 頭 = やや縦長の楕円、胴 = 洋梨（上細・下太）or 台形、手足 = 細い楕円（出典: AnimeOutline）。胴は上底 0.5 W／下底 0.65 W の角丸台形かピル形。
- 脚は太短い円柱（幅 0.18 W、長さ 0.5 H）で左右が接するくらい内側。
- **服の簡略化**: しわ線を描かない。襟・袖口・裾など「境界」だけを線または色替えで。装飾は 1 キャラ 3 要素まで。

## 2. アニメの目（レイヤー化）

### 2.1 レイヤー順（下→上）
1. 白目（上まぶた線と下まぶた線で囲む閉パス）
2. 虹彩ベース色（白目でクリップ）
3. 虹彩上部の暗い帯（上端から 25〜35%）
4. 瞳孔
5. 虹彩下部の明るい反射光（下 30%）
6. メインハイライト（上・光源側）＋サブ（下・反対側、小）
7. 上まぶた線（太い）＋まつ毛
8. 下まぶた線（細い）
9. 眉

### 2.2 形状と比率
- 縦横比: 幼いキャラは**縦 1 : 横 0.8〜1.0**。リアル寄りは 2:1。
- 虹彩: 幅 = 目幅 × 0.65〜0.8、高 = 目高 × 1.0〜1.2（縦長楕円、上下がまぶたで切れる）。中心は目の中心よりわずか下。
- 瞳孔: 虹彩幅 × 0.3〜0.45。大きいほど幼い。
- 虹彩の縁: 幅 = 虹彩幅 × 0.06 の暗い縁取り。
- 上は暗く、下は明るく。
- ハイライト: メイン = 虹彩幅 × 0.3 の円（左上、中心から (−0.25, −0.3) 虹彩幅）、サブ = ×0.12（右下）。全キャラで光源方向を統一。
- 上まぶた幅 = 目幅 × 0.10〜0.14、下まぶた = × 0.03〜0.04（**3〜4 倍差**）。下まぶたは目尻側 60% のみ。
- まつ毛: 目尻側に先細り三角 1〜3 本（根元幅 = 目幅 × 0.06、長さ × 0.25、外上 30〜45°）。
- 目尻の角度: 下がる=たれ目（穏やか）、上がる=つり目。上まぶた端点 y を ±0.1 目高で制御。

### 2.3 記号的な表情
- `^ ^`: 上向き弧のみ。高さ = 目高 × 0.35、線幅は上まぶたと同じ。
- `> <`: 目頭側を頂点とする V 字（横倒し）、開き角 40〜60°。
- `-`: 水平か目尻わずか下がり（高さ 0.05 目高）。
- 驚き: 目 ×1.2、真円に、虹彩 ×0.6。
- 涙目: 下まぶたに白〜水色の薄い楕円（目幅 × 0.8 × 0.15）、ハイライト 2→4。
- チーク: 楕円塗り、または短い斜線 2〜3 本（長さ 0.06 W、間隔 0.03 W、60〜70°）。

## 3. 髪

### 3.1 構造
- **前髪・横髪・後ろ髪の 3 ブロック**、すべて**つむじを起点**に放射状。
- 描画順: **後ろ髪 → 頭・顔 → 耳 → 横髪 → 前髪 → アホ毛**。
- 髪のシルエットは頭蓋より外側に**ボリューム 0.08〜0.12 H**（髪 = 頭蓋円の 1.1〜1.2 倍）。
- 生え際 y ≈ 0.25〜0.3 H。前髪は目の上端〜目の中ほど（y ≈ 0.5〜0.6 H）で終わる。眉がわずかに隠れる長さが標準。

### 3.2 房（tuft）の形
- 「房はリボンのように先端へ細くなる。光の当たる面にハイライト、反対に影」（出典: Wacom）。
- 1 房 = **先が尖った葉形**。根元幅 w、長さ L、中央部で最大幅。**外側の輪郭を外に膨らませ、内側は内に凹ませる**。
- 前髪の房数: **3〜7**。幅を 1 : 1.4 : 0.8 のように不揃いに、長さも ±15% ばらす。
- 先端方向は放射状（つむじから）＋わずかに内向き or 外向き。分け目は中心から ±0.15 W ずらす。
- 切れ込み・重なりは等間隔にしない。
- **横髪**: 前髪より長く、曲率控えめに真下へ。耳の前に 1〜2 房、長さ 0.5〜1.0 H。
- **後ろ髪**: 一つの大きな塊で作り、末端にだけ 3〜5 個の尖り。
- **アホ毛**: つむじから S 字 1 本。長さ 0.25〜0.4 H、根元幅 0.04 W。
- **ポニーテール / ツインテール**: 結び目を中心に放射状。流れは 3 方向以上。ポニー結び目 (x=0, y=0.15 H)、ツイン (x=±0.45 W, y=0.2〜0.35 H)。結び目に小さな楕円（リボン）、そこから 3〜5 房を扇状に。

### 3.3 ハイライト（天使の輪）と影
- 「頭を球体として捉え、反射は**三日月型**」「眉より上が明るい」。
- 天使の輪: 中心 y ≈ **0.15〜0.25 H**、幅 = 髪幅の 0.7〜0.9、帯の高さ 0.04〜0.07 H。**下辺を房の境界でジグザグに削る**。
- ハイライト色: ベースより明度 +20〜30%、彩度やや低め。
- 影: (a) 後ろ髪全体を 1 段暗く、(b) 前髪の房の重なりに細い三角影、(c) 前髪下端に沿っておでこに落ち影。つむじ付近にしずく型の影。

## 4. 線画

### 4.1 線の太さ
- 外側の輪郭線はやや太く、内側（目・鼻・口・しわ・房）は細く。均一な細い線は硬い印象。
- 慣例「12 / 6 / 3 px（A4 350dpi）」— **比率 4 : 2 : 1**。

| 用途 | 幅（全高 1000px 時） |
|---|---|
| シルエット外周 | **6〜8 px** (全高の 0.7%) |
| パーツ境界（前髪と顔、袖、襟） | 3〜4 px |
| 内側の細部 | 1.5〜2 px |
| 上まぶた | 8〜12 px |
| 下まぶた | 2 px |

- 影側の輪郭を光側より 1.3〜1.5 倍太く。
- 線色は真っ黒でなく、隣接する塗り色を暗くした色。

### 4.2 入り抜き
- 中心線に沿って幅を可変にした閉ポリゴン。w(t) = w_max × sin(π t)^k（k=0.5〜0.8）、または入り 0→w_max を t=0.15、抜きを t=0.85〜1.0。房の切れ込みは「入りだけ太く、抜きは尖らせる」。
- 閉じた輪郭線は入り抜きせず太さ一定＋あご付近だけ太く。

### 4.3 図形の重ね合わせで輪郭を省く
- 各パーツを**塗りつぶし閉パス**として重ね、線は「合成結果の外周」と「必要な境界」だけ。
- 「外周だけ線」= 全パーツを太線付きで描いた上に線なし版を再描画する 2 パス描画。
- ステッカー白フチ: union 形状を白で `lineWidth = 2 × オフセット`、`lineJoin='round'`。オフセットは全高の 1.5〜2.5%。

## 5. アニメ塗り

### 5.1 レイヤー構成
- **ベース → 1 影 → 2 影 → ハイライト**。ちびは **ベース + 1 影 +（髪と目だけ）ハイライト**。境界は硬い。

### 5.2 影色
- HSL で **H: 肌 −5〜−10°（赤へ）／その他 +10〜20°（青紫へ）、S: +5〜15%、L: −15〜−25%**。2 影はさらに L −10%。ハイライト: L +20〜30%、S −10%。

### 5.3 影の配置（光源は左上）
- **前髪の落ち影**: 前髪下端の輪郭を下へ 0.04〜0.06 H 平行移動した帯を顔でクリップ。
- **首の影**: あご下にあごの輪郭に沿う三日月（高さ 0.06〜0.1 H）。
- 顔の奥側: 光源反対側の頬の輪郭に沿う細い帯（幅 0.03 W）。省略可。
- 髪: 後ろ髪は全面 1 影相当でも可。
- 服: 腕の付け根の下、裾の内側、光源反対側の側面 20〜30%。
- 白目: 上まぶた直下に薄いグレー帯（高さ = 目高 × 0.15）。
- リムライト: 逆光時のみ。幅 0.015〜0.02 W、輪郭の 30〜50% を断続的に。

## 6. 口と口パク

### 6.1 プリセット（口の基準幅 mw = 0.12 W、y=0.82 H）
| 名前 | 形 |
|---|---|
| 閉じ | 幅 mw の緩い弧、中央 2〜3px 途切れ可 |
| 微笑 | 上向き弧、両端をわずかに上げる |
| 猫口 ω | 「3 を下向きにした扇形」。幅 mw × 1.2、高さ 0.03 H |
| 小さい o | 幅 mw × 0.6 の楕円（縦長 1 : 1.2）、内側暗赤 |
| 叫び | 幅 mw × 2〜2.5 の角丸台形（上広・下狭）、舌の楕円（幅 60%）、上辺に歯の帯（高さ 15%） |
| ニヤリ + 八重歯 | 弧の片端（x = +0.35 mw）に下向き小三角（高さ 0.03 H） |
| への字 | 下向き弧 |

### 6.2 口パク
- リミテッドアニメでは**閉じ・中あき・あき の 3 枚**。24fps で 1 文字 **2〜4 コマ**。母音を繋いで不自然なら間に閉じ口を挟む。
- 最小構成 = 3 ビゼーム。`mouthOpen ∈ [0,1]` で制御点を線形補間。4 ビゼーム版: closed / A / I（幅 ×1.4 高さ ×0.3）/ U（小さい o）。
- 開く時は 2 コマ、閉じる時は 1〜2 コマ。3 段階に量子化（0 / 0.5 / 1）した方がアニメらしい。歯・舌は `mouthOpen > 0.6` で表示。

## 7. リグの動き（Live2D 的パラメータ）

| ID | 意味 | 範囲 |
|---|---|---|
| ParamAngleX / Y / Z | 顔の向き / 上下 / 傾き | −30〜30 |
| ParamEyeL/ROpen | 目の開閉 | 0〜1 |
| ParamEyeL/RSmile | 笑い目 | 0〜1 |
| ParamEyeBallX / Y | 視線 | −1〜1 |
| ParamBrowL/RY, Form | 眉の上下・形 | −1〜1 |
| ParamMouthForm | 口の変形（怒〜笑） | −1〜1 |
| ParamMouthOpenY | 口の開閉 | 0〜1 |
| ParamCheek | 頬の赤み | 0〜1 |
| ParamBodyAngleX / Y / Z | 体の向き | −10〜10 |
| ParamBreath | 呼吸 | 0〜1 |
| ParamHairFront / Side / Back | 髪揺れ | −1〜1 |

- 口は「変形 × 開閉」の 2 軸ブレンド。頭の 2D 疑似回転は、顔パーツを頭の移動量の 100%、髪 80%、後ろ髪 60% 動かす。
- 呼吸: `breath = 0.5 + 0.5 sin(2π t / T)`, T = 3〜4 秒。胴の縦スケール 1 + 0.015 breath、頭は 100〜150ms 遅れ。
- バウンス: 周期 0.5〜0.8 s、y 振幅 0.03〜0.05 H。着地 scaleX 1.06 / scaleY 0.94、頂点 0.96 / 1.04。**頭は変形させず胴だけ**。最大 ±8%。
- まばたき: 間隔 2.5〜5 s、閉じ 1 コマ → 全閉 2 コマ → 半開き 1 コマ → 開。開く方が遅い。
- 髪揺れ: 房ごとの減衰振動 `θ'' = −k(θ − θ_rest) − c θ' + g · headVelX`、k = 60〜120、c = 2√k × 0.3〜0.5。遅延: 前髪 0 / 横髪 60〜100 ms / 後ろ髪 120〜200 ms。振幅上限: 前髪 ±6°, 横髪 ±12°, ポニテ ±20°。根元 0%・中間 50%・先端 100% × θ で「しなり」。

## 8. 漫符
- 大げさに描く。
- 怒りマーク: 十字に並んだ 4 つの角丸「く」。サイズ 0.12〜0.18 W。額の右上 (x=+0.35 W, y=0.2 H)。0.3 s 周期で ±10%。
- 汗: 涙型、幅 0.06〜0.08 W、高さ 0.12 H、水色＋白ハイライト。こめかみ右 (x=+0.4 W, y=0.35 H)。0.8〜1.2 s で下へ 0.1 H すべる。
- キラキラ: 4 点星（辺を内側に凹ませる）＋小 1〜2 個。0.08〜0.15 W。回転 ±15°・拡縮 0.7〜1.0 を 0.6 s 周期。
- 「!」: 頭上 (y=−0.1 H) に高さ 0.25 H。出現 scaleY 1.3→1.0 の overshoot 3 コマ＋放射線 3 本。
- 「?」: 右上、±10° 揺れ（1.2 s）。「♪」: 幅 0.1 W、上下 0.03 H バウンス（0.5 s）。
- ハート: 拍動 1.0→1.15（0.8 s）。ぐるぐる目: 渦巻き 2.5 巻を 1 回転/s。
- 縦線（青ざめ）: 額に縦線 4〜6 本（長さ 0.15 H、間隔 0.03 W）。
- 集中線: 大きな山 4〜6 本と小さな山 2〜3 本を混ぜる。根元太く先が尖った三角形を 8〜20° 間隔で 30〜60 本、長さ ±30%。
- スピード線: 動きの反対側に水平の細長い三角形 3〜6 本（長さ 0.3〜0.6 H）。
