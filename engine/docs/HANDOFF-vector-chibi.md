# 引き継ぎ: ベクター描画によるチビキャラ生成（表現力向上と手順化）

## 目的
このプロジェクト（Claude エージェントが Canvas2D のコードで動画を描く「Agent Video Studio」）で、
**参考画像なしに、文章の指示だけで「かわいい」チビキャラ（2頭身のアニメ調）をベクター図形として描き、
目・口・髪をモーフィングしてアニメーションできる**ようにする。
ゴールの目安は `examples/vector-demo/` の参考画像 2 枚（猫耳・水色髪の叫び顔 / キャップ・パーカーのウインク）と同等の魅力。

## 前回（このブランチ）の結果と原因
- 判定は外部の Opus 5.5（文脈なし）に「参考画像・生成画像・判定基準」を渡して 8 項目 1〜5 点で採点。v1→v9 で平均 1.9→2.1、全項目 4 未満で不合格。人間側の評価も不合格。
- **根本原因（工程上）**: 前回の環境は外向き HTTP がほぼ遮断されており（clipstudio.net / palmie.jp / ichi-up.net / atam-academy.com / note.com など全て 403）、
  「講座の調査」は検索結果の抜粋のみで行われた。`engine/docs/research-*.md` の数値の多くは抜粋の定性記述を推定で数値化したもので、出典の裏付けがない。
  この事実を先に共有せず作業を進めたのが最大の失敗。
- **根本原因（内容上）**: 髪の房の流れ・布の柔らかさ・線の呼吸といった「絵の魅力」は、比率の公式化だけでは出ず、判定の指摘を公式の微調整に落とす反復では改善しなかった。

## 今あるもの（再利用可）
- `engine/kits/vector.js` … Catmull-Rom 曲線、入り抜き（可変幅ポリゴン）、形状モーフィング、セル塗り（クリップ影・ユニオン輪郭）、アニメ目・口・漫符、二次揺れ。単体で動作。
- `engine/kits/chibi.js` … 比率パラメータから生成するチビキャラのリグ（品質未達。作り直し前提）。
- `engine/VECTOR_GUIDE.md` … 手順、スペック表、構築規則 R1〜R13 と修正案（**出典未検証**のまま）。
- `engine/docs/research-*.md` … 調査 4 本（**検索抜粋ベース。要再検証**）、`judge-rubric.md`（判定基準）、`judge-log.md`（採点履歴）。
- `examples/vector-demo/` … スペック、パラメータ掃引テスト、判定用シート、アニメーション章。
- 描画確認: `node engine/render.mjs --project=examples/vector-demo --sheet=0 --test=<name> --cols=1 --w=1024`（Chrome 必須）。

## 再実施の指示（アクセス可能な環境で）
1. **調査を本文ベースでやり直す**。対象は 4 領域: (a) 2頭身の顔・体の比率と配置、(b) 髪（房の大小・S字の流れ・重なり・天使の輪・落ち影）、(c) 体と服（豆型の胴・1本管の腕・萌え袖・残すシワ・線幅 3 段階）、(d) 獣耳・帽子の一体化。
   `engine/docs/research-*.md` の Sources を出発点に、本文を読み、数値は「出典に書かれた値」と「推定」を明確に分ける。
2. 調査結果を **構築規則（パラメータ・生成公式・合格条件）** として `engine/VECTOR_GUIDE.md` §8 を書き直す。
3. 規則どおりに `engine/kits/chibi.js` を実装し直す。座標の手打ちは禁止、すべて比率からの生成。
4. **自己検証**: 部品ごとのパラメータ掃引シート（頭・前髪・目・耳・体・ポーズ）を描き、破綻がないことを確認してから判定に出す。
5. **外部判定**: 文脈を共有しない別モデル/別セッションに、参考画像・生成画像・`engine/docs/judge-rubric.md` を渡して採点させ、`judge-log.md` に記録。
6. 最低点の項目について「その要素の描き方を調査 → 規則に反映 → 実装 → 掃引で自己検証 → 再判定」を繰り返す。指摘を座標修正で追わない。
7. 合格したら `chapters/intro.js` 相当のアニメーション（まばたき・口モーフ・叫び・ジャンプ）で動きを確認し、`AGENT_GUIDE.md` と GUI の「アニメ・ベクター」を有効化する。

## 合格条件
- 判定基準 8 項目（シルエット / 髪の房 / 目 / 顔配置 / 特徴パーツ / 体と服 / 線 / 影）すべてで、参考キャラ 2 体とも 4 以上。
- 文章の指示（例:「猫耳・水色髪・ポニーテール・ジャケット・叫び顔」）だけから、上記品質で描けること。

## 判断材料
- 2 周目で改善が見られない場合は、公式化アプローチ自体を見直す（例: 人が描いた SVG パーツ集をデータとして持ち、コードは配置・変形・モーフィングに徹する）。
