# 判断基準（ちびキャラのベクター描画の品質評価）

参考画像（ref）と生成画像（gen）を比べ、次の 8 項目を 1〜5 で採点する（5 = 参考画像と同等に魅力的、3 = 破綻はないが魅力で劣る、1 = 明らかに崩れている）。
各項目について「gen のどこが、ref のどこと比べて、どう違うか」を具体的に書く。座標一致ではなく「魅力・かわいさ」の観点で評価すること。合格は全項目 4 以上。

1. シルエットの丸さ・柔らかさ（頭＋髪の外形が丸く柔らかい塊に見えるか）
2. 髪の房の大小・流れ・重なり（大小の房が混ざり、S 字の流れがあり、手前と奥の重なりで奥行きが出ているか）
3. 目の大きさと存在感（頭幅に対する目の比率、まつ毛、虹彩の描き込み、表情の主役になっているか）
4. 顔のパーツ配置（頬の幅、あごの形、目・口の高さ、顔の余白のバランス）
5. 耳・尻尾・帽子など特徴パーツの一体感（頭に生えている／被っているように見えるか、浮いていないか）
6. 体と服の丸み・布らしさ（箱に見えないか、袖・裾の垂れ、頭身バランス）
7. 線の強弱（輪郭と内側の線の太さの差、入り抜き、均一すぎないか）
8. 影とハイライトの意図（光源が一つに見えるか、前髪の落ち影・頬の赤みなど「設計された」影があるか、帯状の無意味な影がないか）

出力形式:
- 各項目: 点数 / 具体的な差分（2〜4 文）
- 最後に「最も点差が大きい 2 項目」と、それぞれについて「こう直せば上がる」という具体的な修正指示（形状・比率・配置の言葉で。コードは不要）
