# ちびキャラ（2頭身）の頭部構築リサーチ — 髪シルエット・房・獣耳・キャップ・ツヤ

（調査メモ。WebFetch は全ドメイン遮断のため検索スニペット主体。「推定」は定性記述を幾何に翻訳した提案値。）

## 0. 前提
- 2頭身の頭は**丸く横長**。目は頭の下端から約 1/4 の高さ、目と目の間隔は目 1 個分。あごは円の外に出さない。
- 2頭身の髪は「毛束が厚めで本数が少ない」。線を減らすことが最重要。個性パーツ（アホ毛、耳、ヘアアクセ）は誇張。
- 土台 = **大きな 1 つの丸 + 少数の太い房 + 誇張したアクセント 1〜2 個**。

## 1. 頭＋髪のシルエットを 1 つの塊に
- 髪は頭のアタリの**一回り外側**（頭頂 +10〜15%、側頭 +5〜10%、下端で 0 に収束）。生え際は頭蓋上端から約 1/3 下（ちびでは目の上端から目 1 個分上）。最大幅は目の高さ〜こめかみ。
- 手順: 楕円 → つむじ/分け目 → 外側に一回り大きい輪郭（つむじから放射） → 前髪・横髪・後ろ髪 → 輪郭をシルエットとして見直し線を減らす。
- ヘルメット/箱に見える原因: 厚みが全周均一、頭頂が平ら、側頭で急に縦線に折れる。→ 頭頂で最厚、側頭で薄く、外側の線は頭の丸みに沿う 1 本の連続弧。頭頂は平らにせず、つむじ側へ 3〜5% 偏らせる。
- コード化: `hairOuter: r(θ) = skull(θ) × (1 + k(θ))`, k(頭頂)=.15, k(側頭)=.08, もみあげ先端で 0。輪郭に房の切れ込みを入れるのは下縁（前髪・横髪の先端）だけ。

## 2. 前髪の房
- 前髪は**大きな 3 ブロック**（中央 + 左右）。毛束は「裏表のあるリボン」→ S 字・ねじれ・重なり。**束の太さにリズム**、切れ目の深さもランダム。
- 手順: 分け目 → 前髪全体を 1 枚の面 → 3 ブロック → 各ブロックを**大・小の房に交互**に割る（切れ込みの深さも深い・浅い交互） → 分け目に近い房が手前、外側ほど奥 → 太い房は先を割る、細い房は尖らせる。
- 数値: 主房 3〜5 本。大:小 ≈ 1 : 0.55 幅、深さ 1 : 0.4（推定）。前髪先端は目の上端に触れる〜わずかに被る。眉相当の位置は必ず隠す。
- 失敗: 房の太さ均一、重なりなし、全部尖らせる、分け目がない。
- コード化: 下縁の基準弧 `baseline(x)` に房先端を配置。パターン「大・小・大・小・大」、w_i = W × (大 1.0 / 小 .55) × jitter(.85–1.15)、落ち込み d_i = D × (1.0 / .4)。外側エッジは 2 次ベジェ 2 本の S 字。先端角 大 60〜90°（丸め可）、小 30〜45°。傾き tilt_i = sign(x_i − partX) × (8° + 12° × |x_i − partX| / halfWidth)。描画順は分け目から遠い順。片側の房数を 1 つ変えて非対称に。

## 3. 横髪と後ろ髪
- 横髪は前髪の端から耳あたりまで、頭のアタリに沿って丸み、毛先もカーブ。もみあげは耳から離す。横髪は前髪と角度を変え、**外側に膨らんでから落ちる**（頭頂ラインから平行な滝）。短い＝幼い、長い＝大人しい。ちびの標準はあご先の高さ ±10%。幅は前髪主房の 1.0〜1.5 倍。
- 後ろ髪は横髪の後ろ。外縁は横髪より外、首の横で丸く収まる。つむじから枝分かれ。
- ケモミミキャラは人間の耳を描かず、髪ともみあげで耳位置をカムフラージュ。
- コード化: 横髪 = P0(±rx×1.08, eyeY − .3ry) → 膨らみ P1(±rx×1.12, eyeY + .2ry) → 先端 P3(±rx×.8, chinY)（内巻き）/ (±rx×1.05, chinY)（外ハネ）。先端は尖り 1 + 内側に切れ込み 1。後ろ髪 = skull×1.15 の楕円下半分、下縁は丸い波 3〜5。頭・横髪・後ろ髪は同色でアウトラインを共有、境界線は横髪の内側にだけ。

## 4. ポニーテール / サイドテール
- 結び目は後頭部カーブの最高点。テールは**一度上に出てから重力で落ちる S 字**。根元で太く中間で最も膨らみ先端で細く 2〜3 に割れる。頭表面に結び目へ向かう収束線 2〜3 本。
- 数値（推定）: 結び目 y = 頭頂から .25〜.35 頭高、正面図では輪郭の外に .05〜.1 頭幅はみ出す。立ち上がり 30〜45°、.3 頭高進んで下向きへ。長さ .8〜1.2 頭高。太さ 根元 .25、最大 .35、先端 0。
- コード化: knot = (±.45rx, cy − .35ry)。中心線 3 次ベジェ knot → +(0.15W, −0.25H) → +(0.35W, +0.4H) → tip +(0.3W, +1.0H)。幅 w(t) = wmax × sin(π t^0.7)。t > .85 で 2〜3 本に分岐。

## 5. 獣耳（猫耳）
- 基本は**少し平べったい正三角形**、2 枚（外耳と内耳）で段差。単純な三角ではなく筒状に厚み、後頭部から緩やかに前傾。直線ではなく丸み。
- 位置: 側頭の人耳位置ではなく**頭頂ライン（生え際ライン）に沿って**、根元が球に接地。**前髪と後ろ髪の境界に挟む**。猫はやや斜め外向き。人耳は描かない。ちびでは大きめ。
- 手順: 10 時と 2 時の位置に根元楕円 → 外縁は外に膨らむ大きなカーブ、内縁はやや直線 → 先端は微小な丸み → 内耳 = 0.65 倍を根元側に寄せ、根元辺を重なる小弧（毛のフサ）→ 根元の手前に小房 2〜3 本を被せ、後ろにも髪 → 髪の輪郭は耳の根元でわずかに盛り上がる。
- 数値: 高さ 頭高の .35〜.5、根元幅 = 高さ × .7〜.8、軸は鉛直から外へ 20〜35°、根元中心は頭頂弧上 ±35〜45°、根元の 15〜25% が髪に埋まる。
- 帽子との併用（推定）: 根元位置は同じ。クラウンに根元楕円と同位置の穴（暗い楕円縁）、クラウン輪郭は耳の外縁に沿って盛り上がる、耳はやや外側・低めに倒す。
- コード化: earBase = pointOnEllipse(skull, 90° ± 40°)、axis = normal を外へ 25° 回転。根元中心を輪郭より .2 H_ear 内側に沈める。外縁 = 制御点を axis の外側に .25 H_ear、内縁 = .05 H_ear、先端半径 .04 H_ear。内耳 = 0.65 倍、根元側へ .1 H_ear。描画順: 後ろ髪 → 耳 → 髪本体（根元 20% を隠す）→ 根元手前の小房 2〜3 本（幅 .15 H_ear、外へ流す）。

## 6. キャップ
- クラウンとつばの 2 パーツ。かぶせる目安: 前は眉骨より上、横は耳の付け根より上。つばはやや斜め下向き、「へ」の字で後傾させると顔と前髪が見える。つばは左右の付け根から向きに合わせた線を引き両端を滑らかなアーチで結ぶ、厚みを持たせる。クラウンは半球（髪の外側に、上は少し離し側面は近く）。前面のくぼみの影。つばの下面は影。
- 失敗: 平らな円盤（上縁と下縁のカーブが同じ / 厚みがない / クラウンが真横から直線で切れる）、クラウンが髪のボリュームを無視して小さい、顔・帽子・つばの向き不一致。
- コード化: crown = ellipse(cx, cy − .05ry, rx×1.18, ry×1.20) を brimline(x) = brimY + sag×(x/rx)² でクリップ（brimY = eyeTop − 1.1 eyeH, sag = .06ry）。つば = 上縁 brimline、下縁は制御点 (cx, brimY + .11H) の 2 次ベジェ（レンズ形）、下に .03H オフセットした「厚み」を暗色で先に描く。顔の落ち影 = つば下縁を .05H 下にずらした帯を顔にクリップ alpha .2。前髪の付け根 y = brimY − .05H（縁の裏）。パネル線 2 本。耳: 根元位置で crown を局所的に押し出し、穴の楕円を暗色で描いて耳を重ねる。

## 7. 天使の輪と髪の影
- 輪 = 頭頂付近に頭の丸みに沿ったリング状の光の帯。「w」の連続、両脇だけ幅広。上側は房でハッキリ、下側は柔らかく。
- 影は**前髪の下（おでこ）、横髪が後ろ髪に重なる部分、襟足**に必ず。おでこ付近を最も明るく、頭頂と毛先付近を暗く。
- 数値（推定）: 輪の高さ = 頭蓋上端から髪高の 25〜35%、太さ 頭高の .03〜.05（両端 1.5 倍）、幅 髪幅の 60〜80%（輪郭まで届かせない）。ジグザグ周期は房幅に同期。額の落ち影 = 前髪先端から下へ .03〜.05H、alpha .15〜.25。
- コード化: ringCenterY = skullTop + .3×(hairlineY − skullTop)、skull を .75 縮小した同心楕円の上側を x∈[−.7rx, .7rx] で切る。上辺 +.02H にジグザグ（山 n = 房数×1.5、高さ .015H）、下辺 −.02H で振幅半分、端だけ幅 1.5 倍。色 = 髪色 明度 +25〜35%。bangShadow = 前髪パスを (0, +.04H) 平行移動し顔にクリップ alpha .2。sideShadow = 横髪パスを後ろ髪にクリップ。crownShadow = 髪本体の下 30% を alpha .15。

## 総括: 5 原則
1. 輪郭は 1 本の連続弧（頭頂 +15%、側頭 +8%、下端 0）。角・直線を作らない。
2. 房は大小交互 + 深さ交互 + 傾きは分け目からの距離に比例。同型の繰り返し禁止。太房は先を割る、細房だけ尖らせる。
3. 横髪は前髪と別の角度で外に膨らんでからあごへ。同色・共有アウトラインで 1 塊に。
4. 耳は根元を輪郭の内側に沈め、10 時 / 2 時、外向き 25°、根元に髪を被せる。人耳は描かない。
5. キャップは髪の外側の半球 + 曲率の違うレンズ形のつば + 厚み帯 + 落ち影。「へ」の字で後傾、前髪は縁の裏から。
