# Vector / chibi guide — drawing characters from a text brief, without a reference image

Read this when `style.md` names the **anime** look (or whenever a character must act with its face). The kits are
`/engine/kits/vector.js` (curves, tapered ink, morphing, cel shading, eye / mouth parts, emotes) and
`/engine/kits/chibi.js` (a formula-driven chibi rig). Load both after `motion.js` in studio.html. The example project is
`examples/vector-demo/` (specs in `lib/shared.js`, an animated chapter in `chapters/intro.js`).

The core idea: **never place coordinates by hand**. A character is a spec of ratios + colours; each part is generated by a
formula whose parameters come from drawing tutorials (`engine/docs/research-chibi-construction.md`). You judge the
result on parameter sweeps and model sheets, adjust the ratios, and only then animate. Hand-typed point lists were tried
first and produced stiff, spiky, off-model drawings: the sweeps are what make the output reliably cute.

## 1. The procedure (text → character → animation)

1. **Read the brief and write the spec** (section 3). Translate words into ratios: "childish / cute" → 1.6–2.0 heads,
   eyes at y .64–.68, size .2–.25; "cool / older" → 2.5 heads, eyes at .58, size .16, tilt .1. Pick a hair style
   (bangs n / part / length, side locks, back style), ears / tail / hat, top / bottom kinds and colours (section 4).
2. **Render the sweeps that matter** for this character with `VIDEO.test(...)` + `render_sheet({ test })`: copy the
   sweep tests from `examples/vector-demo/lib/shared.js`. Judge with the checklist in section 5 and change the spec, not
   the kit. Keep the parameters inside the ranges in section 3: outside them the formulas degrade (spiky hair, onion chin).
3. **Model sheet** (`VIDEO.test('cast')`): the character in 4–6 expressions (round / happy / xx / wink, smile / grin / o /
   shout / cat) at the size it will be used. Fix the spec until every expression reads. This is the on-model reference for
   every shot: chapters call `chibi(c, SPEC, pose)`; they never redraw parts.
4. **Animate with pose parameters** (section 6): expressions are morph targets (`mouthPts`, `eyeOpen`, eye styles),
   motion is bob / tilt / squash / jump / arms / sway / tailWag, all pure functions of `t`.
5. **Check real frames** with `render_sheet` at shot start / end, on hits, and every ~0.1 s around morphs, then iterate.

## 2. Layer order (what the rig draws, back to front)

ground shadow → tail → back hair (mass, ponytail / twin tails) → hood (hoodie) → side locks → legs + shoes → skirt / waist
→ torso (sweater under a jacket, or one hoodie shape) → hanging sleeves → jacket fronts → collar → neck → face fill (+
forehead shadow) → blush → eyes → mouth → hair cap + bangs (one outlined group) → angel-ring highlight (clipped to the
hair) → streaks → hat → ahoge → ears (on top of hair and hat) → hair clip → emote → raised sleeves (in front of the head).

Every group is drawn with `group()`: one thick outline around the union of its shapes, then the fills, so inner
outlines vanish where parts overlap (the "outline the silhouette only" cel look). Inner lines are added with `ink()`.

## 3. The spec: ratios, ranges and what they do

Units: head width = 1. The head box spans y −.5 (top) … +.5 (chin); face fractions f map to y = f − .5.

| key | meaning | cute range | notes |
|---|---|---|---|
| `head.cheek` | y fraction of the widest point | .56–.66 | at the eye line → "puffy cheeks" |
| `head.chin` | 0 round … 1 pointed | 0–.4 | >.6 looks like an onion |
| `head.jaw` | width ratio at 85 % height | .6–.72 | |
| `eyes.y` | eye centre, fraction from the head top | .58–.70 | tutorials: .60–.65; lower = younger |
| `eyes.spacing` | half distance between eye centres | .20–.24 | 1.2–1.5 eye widths apart |
| `eyes.size` | eye width | .16–.26 | the iris inside is .6 × width |
| `eyes.aspect` | height / width | .85–1.05 | 1 = round (young), .8 = calmer |
| `eyes.tilt` | radians, positive = tsurime (upturned) | −.15–.15 | |
| `eyes.iris`, `eyes.lash` | colour, lash amount 0–1 | | |
| `mouth.y`, `mouth.width` | centre fraction, half width | .80–.86, .09–.13 | shout opens to ~.3 |
| `hair.volume` | hair silhouette outside the skull | .08–.14 | tutorial: .08–.12 H |
| `hair.bangs.n` | number of tufts | 3–9 (5–7 best) | widths vary ±30 %, lengths ±10 % from `seed` |
| `hair.bangs.part` | where the parting sits, −1…1 | −.5–.5 | ±.15 W off-centre reads best |
| `hair.bangs.hairline` | fraction from head top | .26–.32 | |
| `hair.bangs.length` | tips land at hairline + length | .26–.36 | eyebrow (.28) … mid-eye (.34) |
| `hair.bangs.curl` | sideways bend of the tips | 0–.35 | tips curl toward the parting; >.5 breaks |
| `hair.bangs.fan` | how much tufts fan out from the parting | .2–.5 | |
| `hair.side.n / length / width / curl` | side locks per side | 1–2 / .6–1.4 / .2–.3 / −.3–.3 | |
| `hair.back.style` | `bob` `long` `ponytail` `twin` | | `length` .3–1, `volume`, `side` for the ponytail |
| `hair.ahoge` | `{ kind: 'loop' \| 'spike', x }` | | |
| `hair.highlight` | angel ring on the crown | true / false | |
| `hair.streaks` | `[{ spine, w, color }]` | | the only free-form strokes (optional accents) |
| `ears` | `{ size, at, tilt, width, inner, color }` | size .4–.7, at .4–.65 | `at` = angle from the top of the skull |
| `tail` | `{ color, side }` | | |
| `hat` | `{ kind: 'cap', color, brim }` | | ears stay on top of the hat |
| `body.heads` | total height in heads | 1.6–2.2 | 2.5+ becomes lanky |
| `body.torsoWidth` | shoulder width | .5–.72 | |
| `body.legWidth`, `body.legGap` | | .15–.2, .14–.18 | |
| `body.top` | `{ kind: 'jacket' \| 'hoodie' \| 'sweater', color, light, dark, inner, badge, sleeve, sleeveWidth }` | | |
| `body.bottom` | `{ kind: 'skirt' \| 'jeans', color, socks, shoes, sole, ripped }` | | |
| `skin`, `skinShade`, `ink`, `lineWidth` | | lineWidth .018–.026 | outline = ~2 % of head width |

Colour rules (cel shading): shadow = base with hue shifted +10–20° (skin: −5–10° toward red), saturation +5–15 %,
lightness −15–25 %; highlight = lightness +20–30 %, saturation −10 %. `mixCol(base, '#1a2a6a', .45)` is a good hair
shadow, `mixCol(base, '#ffffff', .55)` a good highlight. One light source (top-left) for the whole cast.

## 4. Writing a spec from words

| brief says | spec |
|---|---|
| ちび / SD / マスコット | `body.heads` 1.6–1.9, `eyes.y` .66, `eyes.size` .24, `head.chin` .15 |
| 少し大人 / クール | `body.heads` 2.2, `eyes.y` .6, `eyes.size` .17, `eyes.tilt` .1, `head.chin` .4 |
| 元気 / 明るい | `bangs.curl` .3, `ahoge: { kind: 'spike' }`, `hair.side.curl` .2, bright iris |
| おっとり / やさしい | `bangs.n` 4, `curl` .1, `eyes.tilt` −.1, `eyes.aspect` .9, `hair.back.style: 'long'` |
| 猫耳 / 獣耳 | `ears: { size .5, at .52, tilt .12 }`, `tail` |
| ツインテール / ポニーテール | `hair.back.style: 'twin' \| 'ponytail'`, `hair.ribbon: '#…'` |
| ぱっつん前髪 | `bangs.n` 7, `curl` 0, `lengthVar` .03, `fan` .15 |
| 制服 / セーラー | `top.kind: 'sweater'` with `light` collar colour, `bottom.kind: 'skirt'` |
| パーカー / ストリート | `top.kind: 'hoodie'`, `bottom.kind: 'jeans'`, `hat: { kind: 'cap' }` |

## 5. Judging a sweep or model sheet (fix the spec until every line passes)

- **Silhouette**: hair mass reads as one soft blob 1.1–1.2× the skull; no tuft sticks out sideways like a wing; the
  hair-cap edge is never visible between tufts (tufts overlap).
- **Face**: eyes sit in the lower half of the head; bangs end between the eyebrows and mid-eye, never hiding both eyes;
  cheeks are the widest point; chin rounded.
- **Eyes**: upper lid 3× thicker than the lower; iris dark on top, light below, two highlights on the light-source side.
- **Proportion**: head ≥ half the total height; hands and feet tiny; neck hidden or a short stub.
- **Line**: one outline weight for silhouettes, thinner for inner lines; no double outlines inside a group.
- **Colour**: base + one hard shadow + (hair, eyes) one highlight; no gradients except inside the iris.
- **Every expression reads at thumbnail size** (render the sheet at w = 400 too).

## 6. Pose parameters (all pure functions of t)

`chibi(c, SPEC, { x, y, s, ...pose })` — `s` = head width in px.

| group | keys |
|---|---|
| motion | `bob` (head units), `tilt` (rad), `squash` (−.15…+.15, volume-preserving), `jump` 0–1 (legs tuck, shadow fades) |
| limbs | `armL` `armR` (rad: 0 hanging, π/2 out, >1.1 raised & drawn in front of the head), `fists`, `legL` `legR` bend |
| face | `eyes` `'round' \| 'happy' \| 'closed' \| 'xx'` or `[left, right]`, `eyeOpen` 0–1 or `[l, r]`, `look: [dx, dy]`, `brow: { angle, y }`, `blush` 0–1 |
| mouth | `mouth` `'smile' 'grin' 'o' 'shout' 'cat' 'flat' 'sad'` or `mouthPts` from `morph(mouthPts(a), mouthPts(b), k)`, `fang`, `teeth` |
| secondary | `hairSway` (−1…1), `tailWag`, `earTwitch` |
| symbols | `emote: { kind: 'anger' 'sweat' 'sparkle' 'note' 'bang' 'q' 'lines' 'shout', x, y, s, age, color }` |

Helpers: `idle(t)` → `{ dy, tilt, squash }`, `blinkOpen(t, every, seed)`, `follow(fn, t, lag, k)` for hair / tail lag,
`kf(t, keys, ease)` for timed expression changes. Blinks: multiply `eyeOpen` by `blinkOpen(t)` so blinks and expressions
do not fight. Mouth talk: quantise `open` to 0 / .5 / 1 and hold each 2–4 frames.

Timing that reads as acting: anticipation (squash −.1, eyes shut) 0.3 s → hit (mouth morph over 0.15 s with `backOut`,
shake, emote pops) → settle (decaying squash `sin(t·20)·e^(−3t)`). Hair and tail follow the head with 0.08–0.15 s lag.

## 7. Building parts outside the rig

The generators are exported as `PARTS`: `head(ratios)`, `bangs(opts, sway)`, `sideLocks`, `backHair`, `catEar`,
`tuftSpine`, `hairTuft`, `hairProfile`, `torso`, `capsule`. Vector primitives (`shape`, `group`, `taper`, `ink`,
`morph`, `morphShape`, `blend`, `animeEye`, `mouth`, `mouthPts`, `emote`) work on any canvas. Use them for props and
non-chibi characters with the same procedure: ratios → sweep → sheet → animate. Add a new part as a function of ratios,
add a sweep test for it, and only merge it into the kit once the sweep looks good across the whole range.

Deeper background: `engine/docs/research-chibi-construction.md` (proportions, eyes, hair, line, cel shading, mouth
shapes, rig parameters, manga symbols) and `engine/docs/research-vector-techniques.md` (curves, tapered strokes,
morphing, canvas finishing, secondary motion, SVG as data).

## 8. Construction rules (the formulas the rig implements)

Each rule names the rubric item it serves (1 silhouette, 2 hair tufts, 3 eyes, 4 face layout, 5 features, 6 body /
cloth, 7 line, 8 light). Sources and reasoning: `engine/docs/research-chibi-head.md`, `research-chibi-body.md`.
H = head width (1.0 in head units), T = torso height.

**R1 hair outline is one continuous arc (1, 2).** `hairOuter(θ) = skull(θ) × (1 + k(θ))`, k = .15 at the crown, .08 at
the temples, → 0 at the side-lock tips. No flat top, no vertical sides. The crown leans 3–5 % toward the parting.
Tuft notches only on the lower edge (bangs, side locks); the crown → temple → side lock is at most two Béziers per side.

**R2 bangs = big / small rhythm from a parting (2, 4).** 3–5 major tufts. Widths alternate big : small = 1 : .55 (±15 %
jitter), notch depths 1 : .4. Tilt `= sign(x − partX) × (8° + 12° × |x − partX| / halfWidth)`. Tufts nearer the parting
are drawn on top. Big tufts get a split, rounded tip; small tufts a point. Tips touch the top of the eyes (eyeTop + .1
eyeH); the brow line is always covered. One side has one tuft more than the other (asymmetry).

**R3 side locks bulge then fall (1, 2).** From the outer bang, out to skull_rx × 1.12 at eye height, down to the chin
(± 10 %), tip curling in (young) or flicking out (lively). One point + one inner notch per lock. Back hair = skull × 1.15
lower half behind the locks, scalloped hem. Hair mass, locks and back hair share one outline (one group).

**R4 tails leave upward then fall (2, 5).** Knot at (± .45 rx, cy − .35 ry). Centre line: knot → +(.15, −.25) → +(.35,
+.4) → tip +(.3, +1.0) (S curve). Width `wmax × sin(π t^.7)`, tip split in 2–3. Two convergence lines on the head.

**R5 cat ears grow from the hair (5).** Base centre on the hair ellipse at ±40° from the top; axis = surface normal
rotated 25° outward. Height .35–.5 H, base width .75 × height, base sunk 20 % into the hair. Outer edge bows out by
.25 × height, inner edge nearly straight, tip radius .04 × height. Inner ear = .65 scale shifted to the base, fur as
overlapping small arcs. Two or three small hair tufts cover the base. No human ears. With a cap: same base, a dark
hole ellipse under the ear, crown bumped outward at the base.

**R6 cap = hemisphere + lens brim + shadow (5, 8).** Crown = skull × 1.18 upper half, clipped by `brimline(x) = brimY +
sag (x/rx)²`, brimY = eyeTop − 1.1 eyeH, tilted back (「へ」). Brim: top edge = brimline, bottom edge sags to brimY + .11
H (lens), plus a .03 H thickness band underneath, plus a shadow band on the face (alpha .2). Bangs start behind the brim.

**R7 angel ring + three shadows (8).** Ring centre at skullTop + .3 (hairline − skullTop), on a concentric ellipse
scaled .75, x within ± .7 rx, zig-zag synced to tuft count, ends fade before the outline, alpha .5. Shadows: bangs
shifted (0, +.04 H) clipped to the face (alpha .2); side locks shifted onto the back hair; lower 30 % of the hair
darker. One light, top-left.

**R8 torso is a bean (6).** Top width .6 H, max width .8 H at 60 % of T, half-circle bottom; sloped shoulders (20–30°)
from the neck root; sides always convex. Hem = arc following the bean (sag .06 H) + rib band .08 T with 3–5 thin lines.

**R9 arms are one tapered tube (6).** Width .18 H → .14 H (× 1.3 for sleeves). Hanging: W = (± .36 H, 1.0 T). Fists up:
S = (± .3 H, .05 T), E = (± .55 H, −.15 T), W = (± .45 H, −.55 T): fists beside the head at temple height, never above
the crown, never over the face. Left and right differ by ±10°. Elbow = bend of the centre line only; a teardrop line
inside the elbow when the bend > 60°.

**R10 hands and 萌え袖 (6).** Fist = rounded rect .24 × .22 H, r .09 H, rotated 10–20°, thumb bump. Cuff = 1.3–1.5 ×
arm width, edge is an S curve (never a straight line), one slack line above it, the hand shows 0–50 % of its size.

**R11 cloth (6).** At most 4 fold lines: armpit, inner elbow, slack above hem and cuff. Hoodie = bean × 1.1 + rib hem +
pocket trapezoid + hood as a neck ring with one back bulge + strings with aglets. Turtleneck = roll band under the
chin (.55 × .12 H) touching the chin, one fold arc; the chin sinks into it. Pleated skirt = trapezoid .7 → 1.1 H, top
edge convex, 5–7 scallops, one thin valley line each, spacing ∝ cos.

**R12 legs and the jump (6).** Leg = tapered tube .22 → .16 H, no knee line. Standing: A = (± .14 H, T + .5 H). Jump:
front knee K = P + (.15 H fwd, −.05 H), A = K + (.02, .22); back leg K = P + (−.1, .18), A = K + (−.08, .2); toes down,
shoes rotated 20–40°. Shoe = capsule .3 × .14 H pushed 60 % forward, sole line .03 H. Thigh-high top = thick convex arc
with a .02 H bulge above it.

**R13 three line weights (7).** Outer silhouette .020 H, part boundaries .014 H, inner lines .008 H, inner lines
tapered both ends, no line where a front part overlaps a back part.

Acceptance for a rule = its rubric item scores ≥ 4 from the external judge on both reference characters.
